# Records

Durable decision records — one file per decision, so the "why" survives past the
conversation that produced it.

Filename: `NNNN-short-title.md` (e.g. `0001-offline-sync-strategy.md`).
Each record: context, the decision, alternatives considered, consequences.

Tracked in Git. Throwaway scratch notes go in `docs/notes/`, which is gitignored.
